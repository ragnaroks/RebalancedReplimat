# RebalancedReplimat
rebalance for sumghai.Replimat

replimat buildings now has low power consumption and need more building materials

### how to use
download released zip then extract in `SteamLibrary\steamapps\common\RimWorld\Mods` folder, full path like `Z:\SteamLibrary\steamapps\common\RimWorld\Mods\RebalancedReplimat`
